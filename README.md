# Cashflow-Salary-Expense-Tracker
Cash Flow Dashboard is a modern and responsive salary &amp; expense tracking web application built using HTML, CSS, and JavaScript. It helps users manage their finances efficiently by tracking salary, monitoring expenses, visualizing spending analytics, and generating downloadable reports.
Cash Flow Dashboard 💸
Mission 2 – Frontend Development Project

Cash Flow Dashboard is a modern and responsive personal finance management web application developed using HTML, CSS, and JavaScript. The project helps users track salary, manage expenses, analyze spending patterns, and maintain financial awareness through an interactive dashboard.

🚀 Live Features
💰 Add & Save Salary
🧾 Add & Delete Expenses
📊 Interactive Expense Analytics Chart
🌙 Dark / Light Theme Toggle
💱 Multi-Currency Support
📄 Download PDF Expense Report
⚠️ Low Balance Warning System
💾 Local Storage Data Persistence
📱 Fully Responsive Design

📊 Functional Modules
1️⃣ Salary Module

Users can enter and save their monthly salary.

2️⃣ Expense Management

Users can add and delete expenses dynamically.

3️⃣ Analytics Dashboard

Displays expense distribution using a doughnut chart.

4️⃣ Theme & Currency System

Supports multiple currencies and dark/light mode.

5️⃣ PDF Report Generation

Users can download expense reports as PDF files.
