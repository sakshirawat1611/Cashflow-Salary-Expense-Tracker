# Cashflow-Salary-Expense-Tracker
Cash Flow Dashboard is a modern and responsive salary &amp; expense tracking web application built using HTML, CSS, and JavaScript. It helps users manage their finances efficiently by tracking salary, monitoring expenses, visualizing spending analytics, and generating downloadable reports.

# Cash Flow Dashboard 💸

A modern and responsive **Salary & Expense Tracking Web Application** built using **HTML, CSS, and JavaScript**.
The project helps users manage personal finances by tracking salary, monitoring expenses, analyzing spending patterns, and generating downloadable reports.

---

# 🚀 Live Features

✅ Salary Management
✅ Expense Tracking
✅ Remaining Balance Calculation
✅ Interactive Expense Analytics Chart
✅ Dark / Light Mode
✅ Multi-Currency Support
✅ PDF Report Download
✅ Low Balance Warning System
✅ Local Storage Data Persistence
✅ Fully Responsive Design
